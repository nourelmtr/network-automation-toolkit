# Network Automation Toolkit

A Python toolkit for network engineers that automates common operational tasks.

## Features

- Ping devices
- SSH into routers
- Execute commands
- Backup configurations
- Read inventory from YAML/JSON
- Export reports

## Technologies

- Python
- Netmiko
- Paramiko
- YAML
- JSON
- Git

## Future Improvements
